Guide

          
Why Clean Pasted Text?

          

            Text copied from documents, PDFs, websites, social platforms, email clients,
            and writing tools can include invisible formatting that is hard to spot.
            CleanText Shelf helps you inspect that text before it goes into a blog post,
            form, newsletter, code snippet, support ticket, or public message.
          

        


        

          

            
Hidden Characters Can Break Things

            

              Zero-width spaces, non-breaking spaces, directional marks, byte order marks,
              and soft hyphens can make ordinary text behave strangely. They may break
              search boxes, form validation, CSV columns, code examples, JSON, Markdown,
              or content management systems.
            

          

          

            
Clean Links Before Sharing

            

              Copied links often contain tracking parameters such as UTM values, fbclid,
              gclid, and campaign identifiers. The cleaner removes common tracking
              parameters while preserving useful parts of the URL, so the link still works.
            

          

          

            
Redact Personal Details

            

              When enabled, the redaction option masks common email addresses and phone
              numbers. This is useful before sharing examples in support tickets, public
              posts, client messages, or AI prompts. Always review the output yourself.
            

          

          

            
Private by Design

            

              The current version runs in your browser. Pasted text is processed locally
              by the page you loaded, not uploaded to a server. That makes the tool useful
              for everyday cleanup without creating an unnecessary copy of your text online.
