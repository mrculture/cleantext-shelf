# CleanText Shelf

A browser-only UtilityShelf micro utility for cleaning pasted text before publishing or sharing.

## Features

- Reveals invisible Unicode characters in pasted text.
- Removes hidden characters and messy whitespace.
- Converts smart punctuation.
- Cleans common tracking parameters from links.
- Optionally redacts emails and phone numbers.
- Runs entirely in the browser with no backend.

## Practical Limits

- Best experience: up to 100,000 characters.
- Large paste warning: over 250,000 characters.
- Input cap: 500,000 characters.
- Hidden-character preview: first 100,000 characters only.

## Trust Pages

- `terms.html`
- `privacy.html`
- `contact.html`

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Publishing

This static site can be published on Cloudflare Pages, Netlify, Vercel, GitHub Pages, or any standard web host.
